## 8. Accessibilité – à tester à chaque jalon sur le S23

- [ ] Taille de police système au maximum (200 %) : aucun horaire, chiffre ou numéro de chambre tronqué ; les lignes passent en colonne si besoin.
- [ ] TalkBack :
  - chaque carte est lue comme un tout (`accessible` + libellé composé, ex. « Zimmer 412, 4. OG, Abreise, Status offen ») ;
  - le bouton de statut annonce son action (« Zimmer 412 starten ») ;
  - un changement de statut est annoncé (`AccessibilityInfo.announceForAccessibility`).
- [ ] Valeur modifiée : le libellé accessible contient « geändert, vorher 13 ».
- [ ] Toutes les cibles ≥ 48 dp ; l'ordre du focus suit l'ordre visuel.
- [ ] Aucune information portée par la couleur seule (vérifier en mode niveaux de gris).
- [ ] Animations coupées quand « réduire les animations » est actif.
- [ ] iOS (jalons, iPhone emprunté) : VoiceOver et Dynamic Type, mêmes vérifications.
- [ ] **Test utilisateur express** au Jalon 1 (30 min, 2–3 collègues, données fictives). On chronomètre leurs réponses à « Wann fängt dein Dienst an ? Wie viele Gäste essen heute Abend ? ». Objectif : moins de 10 s (road.md, objectif 1).
