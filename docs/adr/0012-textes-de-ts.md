# ADR 0012 – Textes dans un dictionnaire typé de.ts

Statut : accepté · Décision D11 du PLAN §3

## Décision

Dictionnaire typé `de.ts`, sans bibliothèque i18n. Textes d'interface en allemand.

## Pourquoi

Une seule langue en v0.1 ; les textes sont déjà extraits.

## Alternatives écartées

i18next dès le départ.

## Compromis

Passage à i18next le jour où une 2ᵉ langue arrive.
